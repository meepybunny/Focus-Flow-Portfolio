# Focus-Flow-Portfolio
A productivity web application developed as part of a CI/CD team project.



## Project Overview

Focus Flow is a web-based productivity application designed to help students manage their study sessions, stay focused, and organise their tasks.

The application combines study timers, focus tools, task management, and interactive features to create a more engaging study experience.

## My Contributions
1. Study Timer & Focus Mode

Developed a Pomodoro-style study timer with interactive session controls.

Implemented Focus Mode functionality to minimise distractions during study sessions.

Developed website whitelist functionality for managing permitted URLs.

Worked on REST API endpoints for creating, retrieving, and managing user-specific study sessions.

2. Interactive Virtual Pet System

Developed a virtual pet feature that allows users to choose between a cat, dog, or rabbit.

Integrated the selected pet into the study timer interface.

Implemented dynamic pet states that respond to timer events, including starting and pausing study sessions.

Used JavaScript event handling and conditional logic to coordinate pet behaviour with timer functionality.

3. Collaborative Kanban Board

Developed a Kanban board feature to help users organise and manage tasks.

Implemented board creation and joining through unique six-character invitation codes.

Worked on backend APIs for retrieving previous boards, updating board names, and saving board information.

Supported collaborative task management through board membership functionality.

4. Software Testing & Quality Assurance

Developed unit tests using Jest to verify individual functions.

Implemented integration tests using Jest and Supertest to validate API endpoints and interactions between components.

Created end-to-end (E2E) tests using Playwright to test complete application workflows.

Contributed to improving application reliability through automated testing and debugging.
